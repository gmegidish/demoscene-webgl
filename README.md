# demoscene-webgl

Classic demoscene productions, reverse-engineered from their original binaries and rebuilt to run in the browser with Three.js.

| Demo | Group | Year | Platform |
|---|---|---|---|
| [Evoid Droid](evoid-droid/) | Excess & Process | 2007 | Xbox 360 (XNA) |

Each demo lives in its own self-contained folder. Serve the repo root with any static server, or view it on GitHub Pages.

All productions, artwork and music belong to their original authors.
